CONVERT TO DXF — HELP

Drop one or more .dwg files on the page. Each one is turned into a .dxf of the same drawing — every layer, block, hatch, dimension and line type — in the same AutoCAD version it was saved as. When they are done you can download them, or open the drawing straight in RoughDrafter, where it arrives in TRACE.

PRIVATE BY DESIGN

The converting happens inside your browser. Your drawings are never uploaded anywhere. The first time you use the page your browser downloads the converter itself (about 3 MB); after that it is kept and starts straight away.

WHAT IT READS

  • DWG files from AutoCAD R14 through AutoCAD 2018 and later (the 2018 format is still the current one), and from programs that save DWG such as ArchiCAD, BricsCAD and DraftSight.
  • Very new or very unusual objects may not come through perfectly. If a file will not convert, ask whoever sent it to Save As DXF, or as an older DWG version.
