# ADVERTISEMENT

RoughDrafter LITE ad campaign — scripts, video-generator prompts, and the raw material that goes with them.

Tagline everywhere: **ZERO → PLAN IN 5 MINUTES!** (spoken: "zero to plan in five minutes"). The → is a fun cartoon chrome arrow.

## The ads

| File | Ad |
| --- | --- |
| `DRAG-RACE-video-prompt.md` | The 10-second drag race — chair vs. sports car (paste-ready clean video prompt) |
| `DRAG-RACE-script-10s.md` | Drag race, tight 10s cut |
| `DRAG-RACE-script-80s-toy.md` | Drag race, 80s toy-commercial energy (jingle included) |
| `DRAG-RACE-script-original.md` | Drag race, original longer script |

## Folders

- `STORYBOARDS/` — generated storyboard frames (the image-to-video references).
- `VIDEOS/` — generated clips and finished cuts.

## House style

Semi-realistic 1980s airbrushed illustration, halfway between photoreal and cartoon — painted-poster look, striped synthwave sun, neon grid horizon, light VHS grain. Not photorealistic, not flat cartoon.
