Why presets are approximations

AutoCAD and MicroStation muscle memory is typed multi-letter command aliases (PL polyline, TR trim, EX extend), and Revit uses two-letter shortcuts (WA wall, DI dimension). Draft currently binds a single key plus optional modifiers, so each preset is the nearest single-key match — usually the first letter of the alias. Multi-letter key sequences are a possible future upgrade if a preset ever needs to be exact.

How the presets map

  • AutoCAD style — A arc (node tool), Q trim (TR), E extend (EX), I insert for doors/windows (blocks), T toggles the 90° T-square like F8 ortho, Space repeats/commits like the ACAD spacebar, Ctrl+Y redo.
  • Revit style — W wall (WA), Shift+W window/door (WN / DR), D dimension (DI), Q trim (TR), Ctrl+Y redo.
  • MicroStation style — Q element selection (first tool in the task list), P place shape, M trim, mnemonic letters elsewhere; Ctrl+Y stands in for redo because the browser keeps Ctrl+R.
  • ArchiCAD style — A arrow (select), W wall, Shift+D door/window pair, L line; Ctrl+Z / Ctrl+Shift+Z undo/redo as ArchiCAD ships them.

Commands other apps have that Draft doesn't (yet)

Ranked by how often a drafter reaches for them:

  • 1. OFFSET (ACAD O, Revit OF) — copy a line/wall parallel at an exact distance. Probably the single most-used AutoCAD command.
  • 2. MIRROR (ACAD MI, Revit MM) — flip a copy across an axis; half the fixtures in a house are mirrored pairs.
  • 3. COPY / MOVE (ACAD CO / M, Revit CO / MV) — explicit copy and move with a base point and typed distance.
  • 4. FILLET (ACAD F) — join two lines into a clean corner (radius 0) or a radiused one.
  • 5. ROTATE (ACAD RO, Revit RO) — spin around a base point by a typed angle.
  • 6. ARRAY (ACAD AR, Revit AR) — repeat at a spacing; ideal for joists, studs, piles.
  • 7. STRETCH (ACAD S) — window-select and pull geometry, keeping connections (Draft's Extend covers part of this).
  • 8. MATCH PROPERTIES (ACAD MA) — paint one object's layer/type onto another.
  • 9. TEXT / LEADER (ACAD T / LE, Revit TX) — notes with arrows; needed before construction sheets.
  • 10. ALIGN (Revit AL) — snap one element flush with another.
  • 11. SPLIT (Revit SL) — break a wall/line at a point.
  • 12. PIN (Revit PN) — lock an element so it can't be nudged accidentally.
  • 13. TAPE MEASURE (ArchiCAD M) — measure without placing a dimension.
