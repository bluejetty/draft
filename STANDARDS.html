Company Standard Layers

The office layer list. Commands assign these layers automatically as you draft — nobody manages layers by hand — and this list is what a future AutoCAD/DXF export maps onto, so name each layer the way your CAD standard expects.

Layer philosophy: layers follow AIA-style CAD names (A-WALL-EXT, S-SLAB…) so drawings convert cleanly to AutoCAD. Views (PLAN, FLOOR, ELECTRIC…) are display groupings only; this layer list is the source of truth for export. A layer marked not printed (like NO-DRAFT) shows in the drawing spaces but is excluded from LAYOUT model displays and printed output.
Structure rules
FOOTINGS S-FOOTING strip lines are generated by BUILD HOUSE and locked against hand edits. Freeform editing lets drafters select, drag, and delete footing lines like ordinary linework. Freeform footing editing
ELEVATIONS E1–E4 elevation marks place themselves around the plan — E1 at the bottom looking up, E2 left, E3 top, E4 right — so every drawing starts with its four elevations. Turn off for jobs that name or place their own. Standard E1–E4 elevations
ELEV NAMES The office words for the sides the standard elevations look at — E1 FRONT, E2 LEFT, E3 BACK, E4 RIGHT by default. These name the rows in the MODEL sidebar; a drawing can rename its own sides right on the row.
CUT BUBBLES Section and elevation bubbles wear their direction triangle in the office style. TUCKED slides the triangle behind the bubble with its back edge on the cut line and just the point showing; PROUD wears the small triangle out on the bubble's rim. More styles to come.
GABLE CORNER How the gable/eave corner is built and drawn. FLAT CLOSE: the wall finish fills the soffit triangle and the rake wears the 5.5″ fascia. SOFFIT RETURN: the eave soffit wraps the corner as a small cornice return at each lower rake end. PORK CHOP: the boxed corner return — a little pyramid at each lower rake end. FULL BOXED RAKE: the pork chop soffit runs the whole rake. PORK CHOP and FULL BOXED build the gable overhang at HALF the eave overhang (2′ eaves → 1′ rake) for proportion; returns and boxed areas are metal matching the fascia finish.
Room minimums

Preferred MINIMUM room sizes — office preference seeded from the code’s own constants, not a code engine. ROOM TAGS marks rooms under these numbers with a quiet UNDER MIN note; nothing blocks, nothing auto-fixes. AUTO-FURNISH will size against this table later.

BEDROOM NBC-style habitable-room default: the flag fires when a bedroom’s inside area or least dimension drops below the office numbers. sq ft · ft min
KITCHEN Seeded from the auto-kitchen envelope the code already applies (8′ long leg × 5′ short leg). sq ft · ft min
LIVING ROOM Stored for AUTO-FURNISH; the detector has no LIVING category yet, so no tag flag rides on this row. sq ft · ft min
WC / BATH Office default: a 3′ clear width and a small-bath floor. sq ft · ft min

Room tray

The room-name chips the guided tour offers for stamping each floor (board #198) — one name per line, in tray order. Grow it from real plans; names are uppercased and deduplicated on save. An emptied list falls back to the office default.

TRAY CHIPS Stamped names feed the room program — ROOM TAGS naming, UNDER MIN checks where a name maps to a minimums row, and the PROJECT page’s room counts at build time.
Fenestration labels

The office’s three letters for the size beside each opening, for the estimate — G 16W x 8H garage doors in FEET, width then height; D36 for every other door in inches of width; W 36 X 42 windows in INCHES width×height. Plan tags switch with the A-DIMS-WIN and A-DIMS-DOOR layers. The stock lists are which sizes the office orders; schedules and auto-fenestration will pick from them later.

DOORS ON ELEVATIONS Print each door’s size on the elevations too. OFF by default — windows carry theirs on elevations, doors only when the office turns this on.
G — GARAGE Overhead doors, FEET, width first: 16x8 is the 16W x 8H double, 9x8 the single.
D — EXTERIOR Man doors, inches wide: the 2′-8″ man door is D32.
D — INTERIOR Swing doors, inches wide — one family down through the closet run (D36–D18).
D — FRENCH French (double) doors, inches of total width: D72 / D60 / D48, then the interior ladder for smaller closets.
W — WINDOWS Windows, INCHES, width first: W 24 X 36 is 24″ wide by 36″ tall.
